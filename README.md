# SitWell

## Prerequisites

Install the following before starting:

### Node.js
Recommended: v20+

Check version:

```bash
node -v
npm -v
```

### Rust

Install from:

https://www.rust-lang.org/tools/install

Verify:

```bash
rustc --version
cargo --version
```

### Tauri Prerequisites

Follow the official guide:

https://tauri.app/start/prerequisites/

### Git

```bash
git --version
```

## Installation

Clone the repository:

```bash
git clone https://github.com/your-org/sitwell.git
cd sitwell
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run tauri dev
```

Build for production:

```bash
npm run tauri build
```
